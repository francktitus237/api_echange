Integrate in 3 steps

From signup to your first API call in under 5 minutes.

1

Create an account and pick a plan

Sign up, select your subscription. Once validated, your fxp_... API key is generated automatically — manage it in your dashboard.

2

Configure the key in your project

One environment variable is all you need. Send it via the X-API-KEY header:

# Your project's .env FOREX_API_KEY=fxp_your_api_key FOREX_API_URL=https://api-forexplatform.sendbid.app/api/v1
3

Make your first call

# cURL curl -H "X-API-KEY: fxp_your_key" \ https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/ # Python import requests r = requests.get("https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/", headers={"X-API-KEY": "fxp_your_key"}) print(r.json()) # {"from": "USD", "to": "EUR", "rate": 0.92, ...} # JavaScript / mobile app const res = await fetch("https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/", { headers: { "X-API-KEY": "fxp_your_key" } }); const data = await res.json();

Frequently asked questions

Everything you need to know before getting started.

Where do the exchange rates come from?

From multiple official sources synced automatically: the European Central Bank (ECB, official daily fixings) plus market providers for fresher data. Every rate includes its last sync timestamp.

How do I get my API key?

Create an account, pick your plan. Once your subscription is activated, an fxp_... key is generated automatically. You can then create additional keys (one per app) from your dashboard.

How do I integrate the API in my app?

A single header: X-API-KEY: fxp_your_key. Works from any language or framework — mobile apps (Swift, Kotlin, Flutter), websites (JavaScript), backends (Python, PHP, Node.js). See full examples in the documentation.

What happens if I exceed my quota?

Requests beyond your hourly quota get a 429 response with the reset time. You can upgrade to a higher plan anytime from your dashboard.

Is my data secure?

Your API keys are stored hashed (SHA-256) — even we cannot read them back. Every API request is logged in an audit trail. The full key is displayed only once at creation.
