توثيق تفاعلي

Swagger UI وReDoc مولّدان تلقائياً — اختبر كل نقطة نهاية من متصفحك.

التكامل في 3 خطوات

من التسجيل إلى أول طلب API في أقل من 5 دقائق.

1

أنشئ حساباً واختر خطتك

سجّل، واختر اشتراكك. بمجرد التفعيل، يتم إنشاء مفتاح fxp_... تلقائياً — أدره من لوحة التحكم.

2

اضبط المفتاح في مشروعك

متغير بيئة واحد يكفي. أرسله عبر ترويسة X-API-KEY:

# .env الخاص بمشروعك FOREX_API_KEY=fxp_your_api_key FOREX_API_URL=https://api-forexplatform.sendbid.app/api/v1
3

نفّذ أول طلب

# cURL curl -H "X-API-KEY: fxp_your_key" \ https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/ # Python import requests r = requests.get("https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/", headers={"X-API-KEY": "fxp_your_key"}) print(r.json()) # {"from": "USD", "to": "EUR", "rate": 0.92, ...} # JavaScript / تطبيق الجوال const res = await fetch("https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/", { headers: { "X-API-KEY": "fxp_your_key" } }); const data = await res.json();

الأسئلة الشائعة

كل ما تحتاج معرفته قبل البدء.

من أين تأتي أسعار الصرف؟

من عدة مصادر رسمية متزامنة تلقائياً: البنك المركزي الأوروبي (أسعار يومية رسمية) إضافةً إلى مزودي السوق لبيانات أحدث. كل سعر يتضمن طابع آخر مزامنة.

كيف أحصل على مفتاح API؟

أنشئ حساباً واختر خطتك. بمجرد تفعيل اشتراكك، يتم إنشاء مفتاح fxp_... تلقائياً. يمكنك بعدها إنشاء مفاتيح إضافية (واحد لكل تطبيق) من لوحة التحكم.

كيف أدمج الواجهة البرمجية في تطبيقي؟

ترويسة واحدة: X-API-KEY: fxp_your_key. تعمل من أي لغة أو إطار — تطبيقات الجوال (Swift, Kotlin, Flutter)، المواقع (JavaScript)، الخوادم (Python, PHP, Node.js). راجع الأمثلة الكاملة في التوثيق.

ماذا يحدث إذا تجاوزت حصتي؟

الطلبات التي تتجاوز حصتك الساعية تحصل على رد 429 مع وقت إعادة التعيين. يمكنك الترقية لخطة أعلى في أي وقت من لوحة التحكم.

هل بياناتي آمنة؟

مفاتيح API الخاصة بك مخزنة مشفرة (SHA-256) — حتى نحن لا نستطيع قراءتها. كل طلب API مسجل في سجل تدقيق. المفتاح الكامل يُعرض مرة واحدة فقط عند الإنشاء.
