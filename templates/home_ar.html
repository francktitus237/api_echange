    توثيق واضح

    التكامل في 3 خطوات

    من التسجيل إلى أول طلب API في أقل من 5 دقائق.

    1

    أنشئ حسابك واختر باقة

    سجّل واختر اشتراكك. فور التفعيل يُنشأ مفتاح API fxp_... تلقائياً، ويمكنك إدارته من لوحة التحكم.

    2

    أضف المفتاح إلى مشروعك

    يكفي متغير بيئة واحد. أرسل المفتاح في ترويسة X-API-KEY.

    3

    نفّذ أول طلب

    اختر لغتك من المثال: cURL أو Python أو JavaScript.

    // JavaScript const res = await fetch("https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/", { headers: { "X-API-KEY": "fxp_your_key" } }); const data = await res.json();

    الأسئلة الشائعة

    كل ما تحتاج إلى معرفته قبل البدء.

    من أين تأتي أسعار الصرف؟

    تأتي من عدة مصادر رسمية تُزامَن تلقائياً: البنك المركزي الأوروبي (أسعار رسمية تُحدَّث يومياً) إضافةً إلى مزودي السوق للحصول على أسعار أحدث. يتضمن كل سعر تاريخ آخر مزامنة.

    كيف أحصل على مفتاح API؟

    أنشئ حساباً واختر باقتك. فور تفعيل اشتراكك يُنشأ مفتاح fxp_... تلقائياً. بعدها يمكنك إنشاء مفاتيح إضافية (مفتاح لكل تطبيق) من لوحة التحكم.

    كيف أدمج الواجهة البرمجية في تطبيقي؟

    تكفي ترويسة واحدة: X-API-KEY: fxp_your_key. تعمل مع أي لغة أو إطار عمل: تطبيقات الجوال (Swift وKotlin وFlutter)، والمواقع (JavaScript)، والخوادم (Python وPHP وNode.js). تجد أمثلة كاملة في التوثيق.

    ماذا يحدث إذا تجاوزت حصتي؟

    الطلبات التي تتجاوز حصتك الساعية تتلقى رداً بالرمز 429 مع وقت إعادة التعيين. يمكنك الترقية إلى باقة أعلى في أي وقت من لوحة التحكم.

    هل بياناتي آمنة؟

    تُخزَّن مفاتيح API بعد تجزئتها (SHA-256)، فلا يمكننا نحن أنفسنا قراءتها. يُسجَّل كل طلب في سجل تدقيق. ولا يظهر المفتاح الكامل إلا مرة واحدة عند إنشائه.
