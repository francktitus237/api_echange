Integra en 3 pasos

Del registro a tu primera llamada API en menos de 5 minutos.

1

Crea una cuenta y elige un plan

Regístrate y selecciona tu suscripción. Una vez validada, tu clave fxp_... se genera automáticamente — gestiónala en tu panel.

2

Configura la clave en tu proyecto

Una variable de entorno es todo lo que necesitas. Envíala mediante el header X-API-KEY:

# .env de tu proyecto FOREX_API_KEY=fxp_your_api_key FOREX_API_URL=https://api-forexplatform.sendbid.app/api/v1
3

Haz tu primera llamada

# cURL curl -H "X-API-KEY: fxp_your_key" \ https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/ # Python import requests r = requests.get("https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/", headers={"X-API-KEY": "fxp_your_key"}) print(r.json()) # {"from": "USD", "to": "EUR", "rate": 0.92, ...} # JavaScript / app móvil const res = await fetch("https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/", { headers: { "X-API-KEY": "fxp_your_key" } }); const data = await res.json();

Preguntas frecuentes

Todo lo que necesitas saber antes de empezar.

¿De dónde provienen los tipos de cambio?

De varias fuentes oficiales sincronizadas automáticamente: el Banco Central Europeo (BCE, tipos oficiales diarios) además de proveedores de mercado para datos más recientes. Cada tipo incluye su marca de tiempo de última sincronización.

¿Cómo obtengo mi clave API?

Crea una cuenta y elige tu plan. Una vez activada tu suscripción, se genera automáticamente una clave fxp_.... Después puedes crear claves adicionales (una por aplicación) desde tu panel.

¿Cómo integro la API en mi aplicación?

Un solo header: X-API-KEY: fxp_your_key. Funciona desde cualquier lenguaje o framework — apps móviles (Swift, Kotlin, Flutter), sitios web (JavaScript), backends (Python, PHP, Node.js). Consulta los ejemplos completos en la documentación.

¿Qué pasa si supero mi cuota?

Las peticiones que superen tu cuota horaria reciben una respuesta 429 con el tiempo de reinicio. Puedes subir a un plan superior en cualquier momento desde tu panel.

¿Mis datos están seguros?

Tus claves API se almacenan con hash (SHA-256) — ni siquiera nosotros podemos leerlas. Cada petición API queda registrada en un registro de auditoría. La clave completa se muestra solo una vez al crearla.

Cuenta gratuita en 2 minutos. Clave API instantánea. Documentación completa.
