Intégration en 3 étapes

De l'inscription à votre premier appel API en moins de 5 minutes.

1

Créez votre compte et choisissez un plan

Inscrivez-vous, sélectionnez votre abonnement. Dès validation, votre clé API fxp_... est générée automatiquement dans votre espace Subscription.

2

Configurez votre clé dans votre projet

Une seule variable d'environnement suffit. Envoyez la clé via le header X-API-KEY :

# .env de votre projet FOREX_API_KEY=fxp_votre_cle_api FOREX_API_URL=https://api-forexplatform.sendbid.app/api/v1
3

Faites votre premier appel

# cURL curl -H "X-API-KEY: fxp_votre_cle" \ https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/ # Python import requests r = requests.get("https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/", headers={"X-API-KEY": "fxp_votre_cle"}) print(r.json()) # {"from": "USD", "to": "EUR", "rate": 0.92, ...} # JavaScript const res = await fetch("https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/", { headers: { "X-API-KEY": "fxp_votre_cle" } }); const data = await res.json();
