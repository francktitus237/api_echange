Intégration en 3 étapes

De l'inscription à votre premier appel API en moins de 5 minutes.

1

Créez votre compte et choisissez un plan

Inscrivez-vous, sélectionnez votre abonnement. Dès validation, votre clé API fxp_... est générée automatiquement dans votre espace Subscription.

2

Configurez votre clé dans votre projet

Une seule variable d'environnement suffit. Envoyez la clé via le header X-API-KEY :

# .env de votre projet FOREX_API_KEY=fxp_votre_cle_api FOREX_API_URL=https://api-forexplatform.sendbid.app/api/v1
3

Faites votre premier appel

# cURL curl -H "X-API-KEY: fxp_votre_cle" \ https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/ # Python import requests r = requests.get("https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/", headers={"X-API-KEY": "fxp_votre_cle"}) print(r.json()) # {"from": "USD", "to": "EUR", "rate": 0.92, ...} # JavaScript const res = await fetch("https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/", { headers: { "X-API-KEY": "fxp_votre_cle" } }); const data = await res.json();

Questions fréquentes

Tout ce qu'il faut savoir avant de commencer.

D'où viennent les taux de change ?

De plusieurs sources officielles synchronisées automatiquement : la Banque Centrale Européenne (BCE, mise à jour quotidienne officielle) et des providers de marché pour une fraîcheur accrue. Chaque taux indique sa date de dernière synchronisation.

Comment obtenir ma clé API ?

Créez un compte, choisissez votre plan. Dès l'activation de votre abonnement, une clé fxp_... est générée automatiquement. Vous pouvez ensuite créer des clés supplémentaires (une par application) depuis votre tableau de bord.

Comment intégrer l'API dans mon application ?

Un seul header : X-API-KEY: fxp_votre_cle. Fonctionne depuis n'importe quel langage ou framework — app mobile (Swift, Kotlin, Flutter), site web (JavaScript), backend (Python, PHP, Node.js). Voir les exemples complets dans la documentation.

Que se passe-t-il si je dépasse mon quota ?

Les requêtes au-delà de votre quota horaire reçoivent une réponse 429 avec l'heure de réinitialisation. Vous pouvez passer à un plan supérieur à tout moment depuis votre tableau de bord.

Mes données sont-elles sécurisées ?

Vos clés API sont stockées hashées (SHA-256) — même nous ne pouvons pas les relire. Chaque requête API est journalisée dans un audit log. La clé complète n'est affichée qu'une seule fois à sa création.
