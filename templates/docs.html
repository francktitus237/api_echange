Documentation API

L'API REST ForexPlatform fournit des taux de change réels (BCE + providers de marché), la conversion de devises et l'historique — pour vos applications mobiles, sites web et backends.

Base URL
https://api-forexplatform.sendbid.app/api/v1

Authentification

Chaque requête protégée requiert votre clé API dans le header X-API-KEY. Votre clé commence par fxp_ et se gère depuis votre dashboard.

Header requis
X-API-KEY: fxp_votre_cle_complete
Important : votre clé complète n'est affichée qu'une seule fois lors de sa génération. Ne la partagez jamais, ne la committez pas dans votre code — utilisez une variable d'environnement.

Premier appel en 30 secondes

Sans clé, testez déjà le service avec l'endpoint démo public :

cURL — sans auth
curl https://api-forexplatform.sendbid.app/api/v1/demo/

Puis avec votre clé, récupérez un taux :

cURL
curl -H "X-API-KEY: fxp_votre_cle" \
     https://api-forexplatform.sendbid.app/api/v1/rates/USD/EUR/
Réponse
{
  "success": true,
  "source": "live",
  "rate": {
    "pair": "USD/EUR",
    "market_rate": "0.8788",
    "timestamp": "2026-09-29T10:03:05Z"
  }
}

Taux de change

Deux façons de consommer les taux : la liste complète pour une devise de base, ou une paire précise.

GET/api/v1/rates/?base={DEVISE}
Tous les taux depuis une base (ex: ?base=USD). Les taux croisés sont calculés automatiquement — n'importe quelle devise peut servir de base.
GET/api/v1/rates/{FROM}/{TO}/
Taux d'une paire précise, ex : /rates/EUR/XAF/. Répond en millisecondes depuis la base synchronisée (fraîcheur ≤ 15 min) ou via les providers live.

Conversion de montant

POST/api/v1/convert/
Convertit un montant avec le taux business (taux marché + spread de votre plan).
ChampTypeDescription
from_currencystringCode ISO, ex "USD"
to_currencystringCode ISO, ex "XAF"
amountnumberMontant positif
cURL — convertir 100 CAD en FCFA
curl -X POST https://api-forexplatform.sendbid.app/api/v1/convert/ \
     -H "X-API-KEY: fxp_votre_cle" \
     -H "Content-Type: application/json" \
     -d '{"from_currency": "CAD", "to_currency": "XAF", "amount": 100}'

Intégration dans vos applications

Python — backend, Django, Flask, scripts

Python + requests
import requests

API_KEY = "fxp_votre_cle"
BASE = "https://api-forexplatform.sendbid.app/api/v1"

r = requests.get(f"{BASE}/rates/USD/EUR/",
                 headers={"X-API-KEY": API_KEY})
data = r.json()
print(data["rate"]["market_rate"])

JavaScript — site web, React, Vue, Node.js

JavaScript + fetch
const res = await fetch(
  "https://api-forexplatform.sendbid.app/api/v1/rates/USD/XAF/",
  { headers: { "X-API-KEY": "fxp_votre_cle" } }
);
const { rate } = await res.json();
console.log(rate.market_rate);

PHP — WordPress, Laravel, Symfony

PHP + cURL
$ch = curl_init("https://api-forexplatform.sendbid.app/api/v1/rates/EUR/XAF/");
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => ["X-API-KEY: fxp_votre_cle"],

$data = json_decode(curl_exec($ch), true);
echo $data['rate']['market_rate'];

Référence des endpoints

GET/api/v1/health/Public
État du service : base de données, cache. Utile pour le monitoring.
GET/api/v1/demo/Public
Échantillon de 10 taux réels — pour tester sans clé.
GET/api/v1/currencies/Public
Liste des 36 devises supportées (code, nom, symbole, drapeau).
GET/api/v1/rates/?base={DEV}Clé requise
Tous les taux depuis une base — taux croisés calculés automatiquement.
GET/api/v1/rates/{FROM}/{TO}/Clé requise
Taux d'une paire précise.
POST/api/v1/convert/Clé requise
Conversion avec taux business (spread selon votre plan).
GET/api/v1/history/{FROM}/{TO}/Clé requise
Historique quotidien OHLC d'une paire.
GET/api/v1/wallets/Clé requise
Wallets multi-devises du compte.
POST/api/v1/transfers/create/Clé requise
Créer un transfert entre utilisateurs.

Le compteur se réinitialise chaque heure. Sur dépassement, l'API renvoie 429 — implémentez un retry avec backoff.

Devises supportées (36)

USD, EUR, GBP, JPY, CHF, CAD, AUD, CNY, HKD, SGD, NZD, SEK, NOK, DKK, MXN, BRL, INR, KRW, ZAR, AED, SAR, TRY, RUB, PLN, THB, IDR, MYR, PHP, VND, EGP, NGN, COP, CLP, XAF, XOF, KMF.

Les francs CFA (XAF, XOF) et le franc comorien (KMF) sont arrimés à l'euro par taux officiel fixe (1 EUR = 655,957 XAF/XOF ; 491,9678 KMF). Tous les croisements (ex : CAD/XAF, USD/XOF) sont calculés automatiquement.
